# Dossier des régions

Ce dossier regroupe les **11 régions du jeu**. Chaque sous-dossier contient une notice descriptive et peut recevoir les images de référence ajoutées par l’utilisateur.

## Liste
1. `01_region_volcanique` — Terres de Braise
2. `02_grande_foret` — Grande Forêt
3. `03_montagnes_enneigees` — Montagnes enneigées
4. `04_canyon_desertique` — Canyon désertique
5. `05_marais_et_sanctuaire` — Marais et sanctuaire
6. `06_ruines_sacrees` — Ruines sacrées
7. `07_cote_des_pirates` — Côte des pirates
8. `08_village_et_campagne` — Village et campagne
9. `09_capitale_royale` — Capitale royale
10. `10_hautes_terres_automnales` — Hautes terres automnales
11. `11_region_finale` — Royaume final des souvenirs oubliés

## Utilisation
- les fichiers `README.md` expliquent comment construire chaque région ;
- les images du dossier servent de références pour Godot ;
- les images ne remplacent pas le level design jouable ;
- la notice générale se trouve à la racine : `NOTICE_GENERALE_DU_PROJET.md`.
